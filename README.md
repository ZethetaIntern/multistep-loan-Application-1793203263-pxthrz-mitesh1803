# LoanEase – Multi-Step Loan Application Form

A production-style front-end internship project built with React + Vite.

## Features
- 8-step loan application workflow
- Personal, Home and Business loan types
- Real-time client-side validation
- Conditional employment/business fields
- Address suggestions/autocomplete simulation
- Document upload with file list and size validation
- PAN/Aadhaar verification simulation
- Auto-save and resume using browser localStorage
- EMI and debt-to-income calculations
- Cross-step validation
- Review summary
- E-signature and consent
- Responsive mobile-friendly UI
- Final application submission screen

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
   npm run dev
5. Open the local URL shown by Vite.

## Notes
This is a front-end demonstration. PAN/Aadhaar verification is simulated and no real financial/identity API is connected.
